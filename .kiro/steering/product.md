# Product Summary

TranscribeCare is an accessible healthcare transcription assistant. It uses the browser's Web Speech API to provide real-time speech-to-text during medical visits, with a focus on high-contrast visuals and large text for readability.

## Core Capabilities

- Live transcription with interim and finalized text segments
- Audio recording with playback at variable speeds
- Session history with search across past transcripts
- Family sharing via Web Share API (WhatsApp and text message integrations mocked)
- Large text accessibility mode toggle

## Target Users

Patients (especially elderly or visually impaired) and their caregivers who need clear, reliable transcriptions of medical conversations.
